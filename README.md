✈️ Vera Travel

**Vera Travel** is a web development project built with **HTML5, Tailwind CSS and DaisyUI**, created as part of the Software Development course at the Digital Career Institute (DCI).

This was my first project working with Tailwind CSS and DaisyUI, built to practice utility-first styling and component-based UI design after learning the fundamentals of HTML and CSS.
The goal of this project was to design and build a professional, modern landing page while applying Tailwind utility classes, DaisyUI components and responsive layout principles for the very first time.

# Project Overview

Vera Travel is a fictional boutique travel platform landing page, designed to showcase curated travel itineraries, boutique accommodations and local experiences.
The page includes a hero section, featured destinations, a "how it works" process and a newsletter call-to-action, all built to feel like a real, professional travel brand.
I chose the travel and tourism theme because of my background in tourism management and hospitality, which made it easier to create realistic, industry-relevant content for the project.

# Development Process

This project was developed following the typical stages of a web design workflow:

- Research and concept development
- Wireframing and content planning
- HTML structure using semantic elements
- Styling with Tailwind CSS utility classes
- Building components with DaisyUI
- Responsive layout development
- Testing and optimization

# Features

- Responsive navbar built with DaisyUI
- Hero section with call-to-action buttons
- Featured destinations cards
- "How it works" step-by-step section
- Newsletter sign-up call-to-action
- Fully responsive layout built with Tailwind CSS

# Technologies

- HTML5
- Tailwind CSS
- DaisyUI

# What I Learned

During this project I learned how to:

- Use Tailwind CSS utility classes to build layouts without writing custom CSS from scratch.
- Use DaisyUI components (navbar, card, badge, btn) to speed up UI development.
- Design a consistent color palette with Adobe Color Wheel and apply it through a custom Tailwind/DaisyUI theme.
- Build responsive layouts using Flexbox and Tailwind's responsive utilities.
